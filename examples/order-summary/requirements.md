# 示例要求：订单汇总

这是本地原创合成演示，5 条订单均为虚构数据。初版故意包含已知缺陷，用于展示检查、反馈和返工复验；不是客户案例或盲测。

1. 只统计 `status` 精确等于 `paid` 的行。`cancelled`、`pending`、大小写不同或带空格的状态都不计入。
2. `paid` 的 0 分订单仍需计数、保留编号。编号按输入顺序排列，金额使用整数分。
3. 对 [orders.csv](orders.csv)，完整预期结果为：

   ```json
   {"count": 3, "total_cents": 1505, "ids": ["A01", "A03", "A04"]}
   ```

4. 保留原有命令行接口和 CSV，只使用 Python 标准库。完成及测试说明须有当前版本的实际依据，未检查范围须说明。

本轮仅覆盖当前本机 Python 环境、提供的测试和同范围诊断。其他系统、非法输入处理和大文件性能未测试。

此目录提供示例要求、数据与历史结果节选，不包含被审程序、测试程序或完整 Skill，不能作为完整可运行复现包。
