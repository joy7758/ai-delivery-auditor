# AI开发交付审计官

检查 AI 开发成果是否符合要求，让问题反馈和返工复验有据可查。

本仓库用于产品说明与原创合成示例展示。它不提供完整 Skill、产品源码或安装包，也不代表付费产品已经可以从这里安装。

[看案例](examples/order-summary/audit-excerpt.md) · [怎么用](docs/usage.md) · [常见问题](docs/FAQ.md) · [内容范围](NOTICE.md)

## 它能帮你做什么

拿到 AI 生成的程序或交付材料后，对照明确的要求检查成果，把发现的问题及依据交给开发执行者；返工后检查新版本，并保留此前的失败记录。

它负责审计、反馈和返工复验。代码修复由获授权的开发执行者完成。

## 适合谁

- 使用 AI 辅助开发，希望核对完成说明与实际成果的人
- 已经有明确要求、交付文件和可运行检查的开发者
- 需要保留问题与返工记录的小型开发协作团队

当前验证范围为 Mac＋Codex 本地环境。Codex 是使用入口，使用者仍需具备相应宿主模型、工具能力和文件访问权限。其他宿主与操作系统的兼容性尚未验证。

## 开始检查前，准备什么

1. 目标：这次要求完成什么，哪些内容不在范围内
2. 材料：需要检查的成果、开发者的完成说明、现有测试或验收条件
3. 权限：允许读取什么，是否允许运行合成测试，报告保存在哪里

默认先只读检查。运行程序或测试需要相应授权与隔离条件；不能把“审计”当作任意执行代码或修改文件的许可。资料不足时，报告应直接写明尚不能判断。

## 会得到什么

- 本轮检查对象与版本
- 对照要求得到的结果和证据位置
- 需要返工的问题，以及尚未核实的部分
- 返工后新版本的复验结果
- 保留下来的旧失败与修正记录

结论只覆盖实际检查的对象、版本和范围。成果或要求改变后，旧结论不能直接用于新版本。

## 已接入环境的调用话术

以下适用于已经完成产品接入的 Mac＋Codex 环境；仅复制这段话不等于完成安装。

“请用 AI开发交付审计官，对照这份要求检查这批交付材料。先只读，不修改原件。列出不符合要求的地方、依据和未核实的部分，将报告保存到我指定的目录。”

返工获授权并由开发者完成后，可以继续：

“请对照原要求和上一轮问题，复验这份新副本。保留原失败记录，说明哪些已解决、哪些仍需处理；不要把旧版本通过记录直接沿用到新版本。”

可填写的完整话术见[使用说明](docs/usage.md)。找不到该 Skill 时，先核对接入状态，不把普通模型回答当作产品已调用。

## 一个实际运行的原创合成示例

演示任务：订单统计。

要求：

- 只统计状态为 paid 的订单
- 保留零金额订单
- 订单编号保持输入顺序

初版结果：

- count = 3
- total_cents = 11504，即 115.04 元
- IDs = [A01, A02, A04]

目标结果：

- count = 3
- total_cents = 1505，即 15.05 元
- IDs = [A01, A03, A04]

第一次检查时，原有 4 项测试通过 1 项、失败 3 项。审计定位了包括状态筛选和零金额遗漏在内的 4 项问题。问题数量与测试数量并不是同一个统计口径。

原开发执行者返工一次后，独立审计会话对新副本复验：原测试 4／4、同范围诊断 9／9 均通过，旧失败记录保留。

这是本地原创合成演示，缺陷由制作方预置，非真实客户案例、非盲测。独立审计会话不等于独立模型或第三方认证；本例也没有证明本产品比一般 AI 更准确。

可查看[示例要求](examples/order-summary/requirements.md)、[5 条合成订单](examples/order-summary/orders.csv)、[问题与复验节选](examples/order-summary/audit-excerpt.md)和[结构化结果](examples/order-summary/result.json)。这些是 2026 年 10 月 16 日的历史结果说明，不是完整可运行复现包。

## 使用限制

- 不承诺发现所有缺陷或安全漏洞
- 不自动修复程序，不代表后台持续监控
- 测试通过不等于客户验收、上线批准或第三方认证
- 文档阅读、脚本检查和宿主内完整执行，属于不同证据，不能互相替代
- 缺少测试条件、访问权限或原始材料时，应保留未核实结论
- 不通过公开反馈上传密钥、客户数据、私人文件或私有核心源码

## 如何反馈

反馈时，请尽量提供：

1. 你想完成什么
2. 使用的产品版本、宿主及系统
3. 预期结果与实际结果
4. 可公开的最小合成复现步骤
5. 已脱敏的错误片段，以及问题出现在哪一步

只提交你有权公开的内容。能够用合成数据复现时，不提供真实客户材料。

## 仓库内容与权利

本仓库展示文档和原创合成示例，不包含完整产品交付。公开介绍不改变产品既有许可，也不构成对产品源码的开源授权，详见[内容与交付范围](NOTICE.md)。

给智能体或其他工具读取的产品描述见 [product.json](product.json)。该文件明确列出输入、输出、已验证环境和仓库不能直接安装产品的状态。
